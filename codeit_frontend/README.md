## Getting Started

Keep `codeit_frontend` and `codeit_backend` in the same parent directory. In the
frontend, `@/types` points to the shared definitions in
[`../codeit_backend/src/types.ts`](../codeit_backend/src/types.ts). Run `npm ci` in both
directories to install their dependencies, including the backend's Zod schema
dependency used for type checking.

Start `codeit_backend` with `npm run dev` on port 3001. The frontend proxies
Axios requests for memo listing, detail, and creation to the backend. Set
`BACKEND_URL` on the frontend server if the backend runs at a different address.

In `codeit_frontend`, run:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.
